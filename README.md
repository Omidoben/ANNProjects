# ANN Models

### 1. Employee Attrition Prediction Using ANN

This project uses an Artificial Neural Network (ANN) to predict employee attrition based on historical HR data.

## Dataset
The dataset used is `Churn_Modelling.csv`, which includes features such as credit score, age, balance, and more.

## Workflow

- Data loading and exploration
- Preprocessing (dummy encoding, scaling)
- Model building using Keras Sequential API
- Training with early stopping and learning rate reduction
- Evaluation using metrics (Accuracy, Precision, Recall, F1, ROC AUC)
- Visualization of training curves
